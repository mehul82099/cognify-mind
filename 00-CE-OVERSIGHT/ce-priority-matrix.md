## Decision Rule

When multiple things need doing, **the highest number wins.** Everything else waits.

| Priority | Definition | Example |
|---|---|---|
| **P0 — Do today** | Blocks revenue, blocks launch, or is the #1 CEO priority | Build first product, launch Gumroad page |
| **P1 — Do this week** | Important but not today-critical | Content consistency, community setup |
| **P2 — Do when P0/P1 clear** | Nice to have, builds long-term | Deep research, nice-to-have features |
| **P3 — Backlog** | Future idea, not now | New product line ideas, collaborations |

# FAQ List — Customer Support Skill Pack

**Edit this file** with your business's actual FAQs.

---

## How to Add an FAQ

One row per FAQ. Format:

```
| keywords (what the customer might type) | answer (what the bot says) |
```

The bot checks if the customer's message contains any of the keywords. If yes → it responds with the answer.

---

---

## Rules

- **Keywords should be what customers actually type.** Think: how would a customer ask this question in a hurry?
- **Answers should be short.** 1–2 sentences max. The bot is front-line, not a blog.
- **If an answer needs a human, escalate.** Add `[ESCALATE]` as the answer for questions that must go to a human.
- **Add as you go.** Every time a customer asks something the bot couldn't answer, add it to this list.

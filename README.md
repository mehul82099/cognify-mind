## Stack Commitment

| Capability | Free Tool Choice |
|---|---|
| Code / agent logic | Free local LLMs + open source frameworks |
| Voice/Speech | Open-source TTS, whisper for transcription |
| Video | Open-source video editing, free stock footage sources |
| Images | Open-source image generation, Canva free tier, free stock |
| Hosting | Free tiers (GitHub Pages, Render, Vercel, etc.) |
| Marketing | Instagram (free), YouTube (free), organic content |
| Transcription | Whisper.cpp / open-source whisper |
| CRM / tracking | GitHub Issues, Notion free tier, spreadsheets |

**Zero paid subscriptions. Every line item must have a free alternative.**

## How This Repository Works

1. **CEO (Sulbha)** commits vision, priorities, decision logs.
2. **Every agent** reads their soulfile + relevant sections before acting.
3. **Skills** are stored in `04-SKILLS-LIBRARY/skills/` — each skill is a folder with its own README + config.
4. **Content** is planned in `05-CONTENT-STRATEGY/`, archived in `10-CONTENT-ARCHIVE/`.
5. **Everything** is tracked: tasks in `08-OPERATIONS/task-board.md`, decisions in `00-CE-OVERSIGHT/ce-decision-log.md`.
6. **When in doubt, check this repo first.** It is the single source of truth.
